# AnimaLink × ANIMA-RAG-Lab — Demo 说明

**时长建议：** 5–8 分钟  
**对象：** 产品 / 工程 / 投资人 demo  
**前置：** 一键启动后打开 UI（见下方）

---

## 一句话介绍

> AnimaLink 紧急分诊：先用 **红灯规则**（本地、毫秒级）拦截危急病例，再对非危急病例做 **Merck RAG 检索回答**，避免不必要的 LLM 调用。

---

## 灯号怎么跟观众讲（30 秒）

界面徽章旁会有白话说明，口播可对齐这三句：

| 灯号 | 白话 | 系统行为 |
|------|------|----------|
| **红灯 RED** | 紧急，先送医 | **已拦截 · 跳过 LLM**，只给急诊指引 |
| **黄灯 YELLOW** | 需小心，持续观察 | 不拦截；给建议 + 知识库；恶化可升级红灯 |
| **绿灯 GREEN** | 暂无紧急信号 | 不拦截；常规知识库 / 可选 LLM 回答 |

**口播：**  
「红黄绿像交通灯：红灯别再问 AI，先送医；黄灯要盯着；绿灯只是『目前没抓到急诊信号』，不是保证没事。」

## Demo 流程（建议 5 个点）

### 案例 1：正常心率（绿灯 GREEN）

1. 点 **「示例：正常心率」**
2. 点 **「开始分诊」**

**预期结果：**
- 徽章：`绿灯 GREEN` + 解释「暂无紧急信号」
- 未拦截 · 有检索来源
- 回答里出现心率参考区间（如 small dog 70–120 bpm）

**口播：**  
「非紧急：红灯放行 → 向量检索 Merck → 带回可追溯来源。」

---

### 案例 2a：中暑轻微（黄灯 YELLOW → 给建议）

1. 点 **「示例：中暑轻微」**
2. 点 **「开始分诊」**

**预期结果：**
- 徽章：`黄灯 YELLOW`（不拦截）
- 有检索来源 / 降温与观察建议
- 解释框强调：虚脱 / ≥104°F 才升级红灯

**口播：**  
「问『中暑怎么办』不等于立刻红灯。先看体温、神志、能否站立——轻的给降温建议，重的才送医。」

---

### 案例 2b：中暑严重（红灯 RED）

1. 点 **「示例：中暑严重」**
2. 点 **「开始分诊」**

**预期结果：**
- 徽章：`红灯 RED` + 解释「紧急，先送医」
- **已拦截 · 跳过 LLM**
- 模型：`red_light_intercept`，耗时约毫秒级
- 症状标签含：虚脱 / 站不起来 / 中暑
- 文案：立即就医 / 途中室温水降温（勿强灌冰水）
- **无检索来源**（刻意跳过）

**口播：**  
「高体温 + 虚脱 → 危急拦截。毫秒级，不烧 token，安全优先。」

---

### 案例 3：巧克力（黄灯 YELLOW · 症状要抓对）

1. 点 **「示例：吃了巧克力」**（或手填：`小狗吃了巧克力，精神还行，有点担心。`）→ 预期 **黄灯**（仅暴露、精神还行；若呕吐/精神差才升红）
2. 点 **「开始分诊」**

**预期结果：**
- `黄灯 YELLOW`（不拦截；尽快联系兽医 + 知识库建议）
- 症状标签是 **「吃了巧克力」**，不是单独的「吃了」
- 文案含可可碱/观察升级条件；出现呕吐、精神差等才升 **红灯**

**口播：**  
「重点是『吃了什么』。只抽『吃了』没有临床意义；巧克力有毒要尽快处理，但精神还行时先黄灯密切观察，别一上来就全红拦截。」

---

### 案例 4：老鼠药中毒（红灯 RED）

1. 点 **「示例：中毒」**
2. 点 **「开始分诊」**

**预期结果：** 同红灯拦截（中毒关键词）

**口播：**  
「体征数值之外，情况描述里的中毒 / poison 也会触发红灯。」

---

### 案例 5（可选）：有毒植物（ASPCA 名录 → 红灯）

1. 情况描述填：`猫吃了百合叶子，现在在吐，怎么办？`
2. 点 **「开始分诊」**

**预期结果：** 红灯拦截；文案可提示 ASPCA 有毒植物 / Poison Control

**口播：**  
「ASPCA 有毒植物名录（约 400+ 种 / 1000 个别名）做绝对匹配——不必等通用『中毒』词。」

## 架构一页纸（可选投影）

```
病例输入（情况描述）
   │
   ▼
红灯规则（本地；含中暑轻重、毒物/巧克力等）
   │
   ├─ 红灯 RED  → 紧急指引（跳过 LLM / 检索）
   │
   └─ 黄 / 绿 → Merck 向量检索 → 回答（可选 LLM）
```

**数据现状：**
- 全量抓取：约 488 篇（紧急/中毒 + 犬猫主人临床章节）
- RAG chunks / 向量：约 13.5k（语义嵌入 `paraphrase-multilingual-MiniLM-L12-v2`；可回退 TF-IDF）
- 默认站点：MSD Vet Manual（`msdvetmanual.com`）

## 可能被问到的问题

**Q：红灯解释在哪里？**  
A：结果区徽章正下方的彩色说明框（「红灯 = 紧急，先送医」等）。下面的「分诊结论」是针对本案的具体指引。

**Q：数据在本地吗？**  
A：是。API、红灯规则、向量库全在本机。红灯路径不调用云端 LLM；黄/绿可选用 OpenAI。

**Q：为什么不是直接问 ChatGPT？**  
A：紧急场景需要确定性、可审计、低延迟。红灯是规则闸门；RAG 提供可溯源的 Merck 依据。

**Q：Merck 为什么用 seed / MSD？**  
A：部分网络对 merckvetmanual.com 返回 403。开发可用 curated / MSD 镜像；有 VPN/可访问后再切 live scrape。

**Q：下一步？**  
A：在 `.env` 填入 `OPENAI_API_KEY` 提升黄/绿回答质量；App 对接见 `docs/APP_INTEGRATION.md`；继续扩毒物与评测用例。

**Q：如何开启 OpenAI？**  
A：`cp .env.example .env`，写入 `OPENAI_API_KEY`，重启 API。顶部应显示「LLM：已开启」。红灯仍不调用云端。
